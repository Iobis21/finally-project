## 1. ტასკების დეკომპოზიცია და Story Points

### როგორ შევაფასე (Planning Poker)

Planning Poker-ში გუნდის თითოეული წევრი ერთდროულად „ხსნის" ბარათს თავისი შეფასებით, მერე განსხვავებულ შეფასებებს განიხილავენ. მარტო ვმუშაობ, ამიტომ ეს პრინციპი ასე გამოვიყენე:

1. თითოეულ თასქზე ჯერ დამოუკიდებლად დავწერე შეფასება;
2. შევადარე **საბაზისო თასქს** — „პროექტის შექმნა" = **2 ქულა** (მარტივი, ვიცი როგორ კეთდება);
3. თუ თასქი ორჯერ რთული მეჩვენა, ავიღე შემდეგი ფიბონაჩის რიცხვი;
4. სადაც ახალი ბიბლიოთეკა მჭირდება (მაგ. JWT, TanStack Table), შეფასება გავზარდე, რადგან სწავლის დროც სჭირდება.

**სკალა:** 1 — ძალიან მარტივი · 2 — მარტივი · 3 — საშუალო · 5 — რთული · 8 — ძალიან რთული / ბევრი უცნობი

## 3. გლობალური სტილები

პროექტი შექმნილია `wms-app/` ფოლდერში (Vite + React + TypeScript + Tailwind CSS v4).

### რა ფაილები შევქმენი/შევცვალე

| ფაილი | რა არის შიგნით |
|---|---|
| `wms-app/src/index.css` | მთელი დიზაინ-სისტემა (იხ. ქვემოთ) |
| `wms-app/vite.config.ts` | Tailwind-ის Vite პლაგინი |
| `wms-app/index.html` | ფონტების ჩატვირთვა Google Fonts-იდან, `lang="ka"` |
| `wms-app/src/App.tsx` | სატესტო გვერდი, სადაც ჩანს ფერები, ღილაკები და სტატუსები |

### `index.css`-ის სტრუქტურა

1. **დიზაინ-ტოკენები (`@theme`)** — Tailwind v4-ში კონფიგურაცია `tailwind.config.js`-ის ნაცვლად პირდაპირ CSS-ში იწერება. აქ განსაზღვრული ცვლადი ავტომატურად ხდება კლასი, მაგ. `--color-primary-600` → `bg-primary-600`.
   - **ფონტები:** Inter (ლათინური) + Noto Sans Georgian (ქართული);
   - **მთავარი ფერი:** ლურჯი (primary);
   - **სტატუსის ფერები:** success (მწვანე), warning (ნარინჯისფერი), danger (წითელი), info (ცისფერი) — საწყობში ბევრი სტატუსია (მარაგშია, კრიტიკული, ამოწურულია, გზაშია).
2. **CSS ცვლადები (`:root`)** — ფონი, ბარათი, საზღვარი, ტექსტი. `.dark` კლასში იგივე ცვლადები მუქი თემისთვის.
3. **Reset (`@layer base`)** — Tailwind-ის Preflight უკვე აკეთებს Reset-ს (margin, padding, box-sizing). დავამატე საბაზისო სტილები `body`-ს, სათაურებს, ბმულებს და ფოკუსს.
4. **რეიუზებადი კლასები** — `.btn-primary`, `.btn-secondary`, `.btn-danger`, `.input`, `.card`, `.badge-success` და ა.შ.
