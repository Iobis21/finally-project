# პრაქტიკული დავალება 8 — სემანტიკური HTML5 სკელეტი

**ფაილები:**
- [index.html](index.html) — მთავარი გვერდი
- [about.html](about.html) — „ჩვენ შესახებ"
- [style.css](style.css) — საბაზისო სტილები

გასახსნელად უბრალოდ გახსენი `index.html` ბრაუზერში.

## გამოყენებული ტეგები

| ტეგი | სად და რისთვის |
|---|---|
| `<header>` | საიტის ზედა ნაწილი: ლოგო, ნავიგაცია, „შესვლა" ღილაკი |
| `<nav>` | მთავარი მენიუ (header-ში) და სოციალური ბმულები (footer-ში); თითოეულს აქვს `aria-label`, რომ განსხვავდებოდეს |
| `<main>` | გვერდის უნიკალური შინაარსი — თითო გვერდზე ერთი |
| `<section>` | თემატური ბლოკები, თითოეულს აქვს საკუთარი `<h2>` (შესაძლებლობები, სიახლეები, მიზანი, გუნდი...) |
| `<article>` | დამოუკიდებელი ერთეულები: როლის ბარათი, სიახლე, გუნდის წევრი |
| `<aside>` | გვერდითი პანელი „სისტემა ციფრებში" |
| `<footer>` | კონტაქტები (`<address>`), სოციალური ბმულები, საავტორო უფლებები |
| `<figure>` + `<figcaption>` | სურათი და მისი აღწერა |
| `<time datetime="...">` | სიახლეების თარიღები, საავტორო წელი |
| `<address>` | საკონტაქტო ინფორმაცია |

## სათაურების იერარქია

**index.html:**
```
h1  საწყობის მართვა — მარტივად და ზუსტად
├── h2  შესაძლებლობები როლების მიხედვით
│   ├── h3  საწყობის მენეჯერი
│   ├── h3  შესყიდვების მენეჯერი
│   ├── h3  ოპერატორი
│   └── h3  ლოჯისტიკის თანამშრომელი
├── h2  სიახლეები
│   ├── h3  დაემატა შტრიხკოდის სკანირება
│   └── h3  კრიტიკული მარაგის შეტყობინებები
└── h2  სისტემა ციფრებში (aside)
```

**about.html:**
```
h1  ჩვენ შესახებ
├── h2  პროექტის მიზანი
├── h2  რა პრობლემას ვჭრით
│   ├── h3  ქაღალდის ჟურნალები
│   └── h3  გაურკვეველი მარაგი
├── h2  გუნდი
└── h2  ტექნოლოგიები
```

თითო გვერდზე მხოლოდ ერთი `<h1>`, დონეები არ გამოტოვებულა (h1 → h2 → h3).

## დამატებით
- `lang="ka"` — ბრაუზერმა და ეკრანის წამკითხველმა იცის, რომ გვერდი ქართულია;
- `aria-current="page"` — მენიუში აქტიური გვერდი;
- ყველა `<img>`-ს აქვს `alt` ტექსტი და `width`/`height`;
- `<div>` გამოყენებულია მხოლოდ ერთხელ (`.with-sidebar`) — სუფთა ლეიაუთისთვის, სადაც შესაბამისი სემანტიკური ტეგი არ არსებობს.
