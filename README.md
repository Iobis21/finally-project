# 📦 WMS — საწყობის მართვის სისტემა

**ფინალური პრაქტიკული პროექტი (React) · ვარიანტი №2: საწყობის მართვის სისტემა როლების მიხედვით**

როლებზე დაფუძნებული ვებ-აპლიკაცია საწყობისთვის. სისტემაში მარაგები ჩანს რეალურ დროში, კრიტიკული ნაშთი ავტომატურად ინიშნება, საქონლის ჩამოწერა უარყოფითი ნაშთისგან დაცულია, და თითოეულ თანამშრომელს მხოლოდ თავისი სამუშაო სივრცე უჩანს.

## 🎯 ბიზნეს-აღწერა

**პრობლემა:** ბევრ საწყობში მარაგი ქაღალდზე ან Excel-ში აღირიცხება. ამის გამო საქონელი იკარგება, მოულოდნელად მთავრდება და თანამშრომლები ერთმანეთის სამუშაოში ერევიან.

**გადაწყვეტა:** ერთი სისტემა, სადაც ყველა ოპერაცია აღირიცხება, თითოეული როლი კი მხოლოდ საჭირო ფუნქციებს ხედავს.

| როლი | რა შეუძლია |
|---|---|
| 🧑‍💼 **საწყობის მენეჯერი** | ყველა გვერდი; პროდუქტის დამატება, რედაქტირება, წაშლა და ჩამოწერა; თანამშრომლების როლების განაწილება და დაბლოკვა |
| 🛒 **შესყიდვების მენეჯერი** | მარაგების ნახვა, კრიტიკული ნაშთის კონტროლი, შეკვეთები, ანგარიშები |
| 👷 **ოპერატორი** | მარაგების ნახვა, დაზიანებული ან დაკარგული საქონლის ჩამოწერა, მიღება და გაცემა |
| 🚚 **ლოჯისტიკის თანამშრომელი** | მარაგების ნახვა, გაცემა, მიწოდებები |

## ✨ ფუნქციონალი

- 🔐 **ავტორიზაცია:** შესვლა და რეგისტრაცია ელ-ფოსტით და პაროლით (JWT, bcrypt), დაცული მარშრუტები, 403 გვერდი;
- 👥 **როლები (RBAC):** მენიუ, გვერდები და ღილაკები როლის მიხედვით. ახალი მომხმარებელი ოპერატორად რეგისტრირდება, როლს მენეჯერი ცვლის;
- 📋 **მარაგები:**
  - ძებნა სახელით, SKU-ით ან შტრიხკოდით (Debounce 300ms);
  - ფილტრები და სორტირება;
  - დამატება, რედაქტირება და წაშლა მოდალურ ფანჯარაში (Portal), ვალიდაციით;
- 📉 **ჩამოწერა:** ნაშთზე მეტის ჩამოწერა შეუძლებელია (Zod + სერვერზე შემოწმება);
- 🔴 **კრიტიკული მარაგი:** პულსირებადი ინდიკატორი და Dashboard-ის სტატისტიკა;
- 🛡️ **მდგრადობა:**
  - ErrorBoundary „სცადეთ ხელახლა“ ღილაკით;
  - ოფლაინ რეჟიმი: სერვერის გათიშვისას ქეში ან დემო მონაცემები ბანერით;
  - ორმაგი დაჭერის ბლოკი;
- ⚡ **წარმადობა:** React.lazy, React.memo, useCallback, useMemo, WebP სურათები `loading="lazy"`-ით;
- 📱 **რესპონსივი:** მობილურზე ☰ მენიუ, ცხრილები ბარათებად, Grid + Flexbox;
- ♿ **ხელმისაწვდომობა:** კლავიატურით ნავიგაცია, `:focus-visible`, `aria-*`, კონტრასტი WCAG AA.

## 🛠️ ტექნოლოგიები

| კატეგორია | ტექნოლოგია |
|---|---|
| UI | **React 19**, **TypeScript** |
| აწყობა | **Vite** |
| მარშრუტიზაცია | **React Router** |
| სტილები | **Tailwind CSS v4** + კომპონენტური CSS ფაილები (BEM), CSS ცვლადები |
| სთეით-მენეჯმენტი | **Context API + useReducer** (გლობალური Store, localStorage persistence) |
| ფორმები და ვალიდაცია | **React Hook Form** + **Zod** |
| იკონები | **Lucide React** (SVG) |
| HTTP | Fetch API (საერთო `apiClient` სერვისის ფენით) |
| Backend (Mock API) | **json-server** + **json-server-auth** (JWT) |
| ხარისხი | Prettier, Oxlint, TypeScript strict |

> Axios-ის ნაცვლად გამოყენებულია ბრაუზერის `fetch`, საერთო `request()` ფუნქციით. MUI-ის ან Styled Components-ის ნაცვლად გამოყენებულია Tailwind და BEM-ით დაწერილი CSS.

## 🚀 ლოკალურად გაშვება

**საჭიროა:** [Node.js](https://nodejs.org/) 20 ან უფრო ახალი და Git.

```bash
git clone https://github.com/Iobis21/finally-project.git
cd finally-project/wms-app
npm install
npm run dev
```

`npm run dev` ერთდროულად უშვებს ორ სერვერს:

| სერვერი | მისამართი |
|---|---|
| 🌐 საიტი (Vite) | http://localhost:5173 |
| 🗄️ API (json-server) | http://localhost:3000 |

### სხვა ბრძანებები

| ბრძანება | რას აკეთებს |
|---|---|
| `npm run build` | საბოლოო ვერსიის აწყობა (`dist/`) |
| `npm run preview` | აწყობილი ვერსიის ნახვა |

## 📁 სტრუქტურა

```
wms-app/
├── db.json              ← მონაცემთა ბაზა (json-server)
├── public/images/       ← WebP სურათები
└── src/
    ├── components/      ← მრავალჯერადი UI კომპონენტები (Header, Sidebar, Modal, Button, ...)
    ├── pages/           ← გვერდები (auth, dashboard, inventory, users, errors)
    ├── hooks/           ← ლოგიკა: useItems, useInventoryFilters, useDebounce, useUsers
    ├── services/        ← API მოთხოვნები (apiClient, itemService, authService)
    ├── context/         ← AuthContext (სესია, უფლებები)
    ├── store/           ← გლობალური Store: InventoryContext + useReducer + localStorage
    ├── config/          ← როლები და უფლებები
    ├── routes/          ← ProtectedRoute, GuestRoute, RoleRoute
    ├── schemas/         ← Zod ვალიდაცია
    ├── types/           ← TypeScript ინტერფეისები
    └── utils/           ← დამხმარე ფუნქციები
```
