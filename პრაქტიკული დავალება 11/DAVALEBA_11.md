# პრაქტიკული დავალება 11 — ინტერაქციული მართვის პანელი

**პროექტი:** WMS — მარაგების გვერდი (`/inventory`)

## რა გაკეთდა

მარაგების გვერდზე შეიძლება ნივთის **დამატება**, **რედაქტირება** და **წაშლა**. ფორმა იხსნება **მოდალურ ფანჯარაში**, ცვლილება კი სიაში მაშინვე ჩანს, **გვერდის განახლების გარეშე**.

## 2. მოდალური ფანჯარა (Portal)

**ფაილი:** [Modal.tsx](../wms-app/src/components/ui/Modal/Modal.tsx)

```tsx
return createPortal(
  <div className="modal__overlay" onClick={onClose}>          {/* ფონზე დაჭერა → დახურვა */}
    <div className="modal" onClick={(e) => e.stopPropagation()}> {/* შიგნით — არა */}
      <button onClick={onClose}>✕</button>                     {/* ღილაკით დახურვა */}
      {children}
    </div>
  </div>,
  document.body,                                                {/* იხატება <body>-ში */}
)
```

- იხსნება ღილაკებით **„+ ახალი ნივთი“** (დამატება) და ✏️ (რედაქტირება);
- იხურება **✕ ღილაკით**, **ფონზე დაჭერით**, **„გაუქმება“-თი** და **Esc-ით**;
- `createPortal` მოდალს `<body>`-ის ბოლოში ხატავს, ამიტომ მას არც მშობლის `overflow` ჭრის და არც `z-index`;
- წაშლაზეც იგივე Modal გამოიყენება, უბრალოდ შიგნით სხვა შიგთავსით (`ConfirmDialog`).

## 3. დინამიკური განახლება

**ფაილი:** [useItems.ts](../wms-app/src/hooks/useItems.ts)

```ts
async function addItem(data) {
  const created = await createItem(data)     // POST /items
  setItems((prev) => [...prev, created])     // სიაში დამატება
}
async function editItem(id, data) {
  const updated = await updateItem(id, data) // PATCH /items/:id
  setItems((prev) => prev.map((i) => (i.id === id ? updated : i)))
}
async function removeItem(id) {
  await deleteItem(id)                       // DELETE /items/:id
  setItems((prev) => prev.filter((i) => i.id !== id))
}
```

ჯერ სერვერზე ვინახავთ, შემდეგ კი იგივე ცვლილებას state-შიც ვაკეთებთ. React ცხრილს ხელახლა ხატავს და Refresh საჭირო აღარ არის.
